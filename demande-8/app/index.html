Lovable, et l'Usine à services
de rAIme

Basile a demandé : aller chercher le code source de Lovable, l'installer et le faire tourner, pour créer des applications de services. Voici ce que dit l'enquête, ce qu'on a trouvé sur GitHub, et une fabrique qui fonctionne ici, sans clé externe : décrivez un service, elle génère une vraie page de vente dans le navigateur.

1Le constat : Lovable n'a pas de code source public

Lovable (lovable.dev) est un service propriétaire (fermé) : aucune entreprise ni auteur ne publie son code sur GitHub. On ne peut donc ni le « récupérer » ni l'« installer » tel quel. En revanche, son ancêtre open source existe et est public : il a été écrit par le fondateur de Lovable, Anton Osika.

  • Ancêtre officiel — AntonOsika/gpt-engineer est explicitement annoncé comme « le précurseur de lovable.dev » dans son README. Licence MIT. Mais le dépôt est archivé et, pour générer réellement du code, il exige une clé OpenAI/Anthropic.
  • Le projet Lovable lui-même n'a aucun dépôt public. Ce que l'on trouve sous « lovable » sur GitHub sont des cours, des prompts système « leakés », ou des clones non officiels.

2Les équivalents open source trouvés sur GitHub

Le plus fidèle est l'ancêtre officiel gpt-engineer. Les clones « style Lovable » les plus vivants sont :

  • gpt-engineer — l'ancêtre du fondateur, MIT, CLI Python. installé
    n'appelle jamais d'API sans clé ; archivé.
  • firecrawl/open-lovable — « recréez n'importe quel site en React », MIT, ~28 500 ★. cloné
    exige clé Firecrawl + fournisseur IA + sandbox (Vercel/E2B).
  • freestyle-sh/Adorable — « Open Source Lovable », Next.js + VMs Freestyle, MIT. cloné
    exige clé Freestyle + clé IA pour fonctionner.
  • lak7/devildev — « Lovable orienté specs, open source », TypeScript, Apache-2.0. repéré
    candidat prometteur à évaluer plus tard.

Point commun : aucun de ces outils ne produit quoi que ce soit sans clé d'API (OpenAI, Anthropic, Firecrawl, Freestyle…). Comme la consigne interdit d'en écrire une, la démonstration vivante ci-dessous fonctionne entièrement dans le navigateur, en réutilisant la logique réelle de l'atelier du cerveau de rAIme (« d'une phrase, un service vendable »).

3La fabrique — générez une page de service en direct

Écrivez une phrase de service. Le moteur (calqué sur atelier/site.js du cerveau) en déduit un nom de sous-domaine et une palette, puis rend une page de vente complète. Tout est local : rien ne part, aucune clé.
