| Outil | Version | Portée |

## Résultats
- **AgentShield : note C (60/100), 26 constats, aucun réel défaut exploitable.**
  - 14 « critiques — clé Azure en dur » : ce sont les 14 empreintes `sha512` d'intégrité de `package-lock.json`, publiques par nature. **Faux positifs**, vérifiés ligne à ligne.
  - 12 « défenses de consigne absentes » : tous dans `site/CLAUDE.md`, notes de travail de la session locale (pas une consigne exposée au public). Risque faible ; à compléter **à la source sur le PC** (le dossier `site/` est recopié depuis le PC et serait écrasé).
  - 68 flux « entrée → écriture ou réseau » : variables d'environnement et arguments de commande (maîtrisés par Basile) ; les requêtes SQL sont paramétrées (`$1`, `$2`) : pas d'injection SQL.
- **npm audit : 0 vulnérabilité.**
- **Historique git : aucune clé** dans les 128 commits. Contre-épreuve : deux fausses clés glissées dans un texte sont bien trouvées par la même recherche.
